PLAY MC-1

NEON SPIRAL / EFFECTS

While stopped: press GLO three times, turn KNOB4 clockwise to load NEON SPIRAL, then PLAY. Loading replaces the working project. HOME then FX opens SENDS for the selected track; SELECT changes tracks. Knobs 1-4 set R/D1, C/F1, R/D2 and C/F2 sends (0-127, zero is dry). ENV switches SENDS / TYPES. TYPES sets the four global shared banks for all four tracks, 0-7 each: each R/D bank offers ROOM1-3, HALL1-2, PLATE, DELAY and PANNING DLY; each C/F bank offers CHORUS1-4, FB CHORUS, FLANGER, SHORT DLY and FB SHORT DLY. These are original approximations, not Roland algorithms. The master has volume and limiter only.

PARTS AND SOUNDS

SELECT chooses three melodic parts or drums. PRESETS opens a 128-preset or eight-kit list that closes after 0.5 seconds without input. Turn slowly for fine changes and quickly for larger jumps. ALGORITHM queues any of 64 patterns, each with 16 steps and four parts. Modified sounds retain their preset name with *. GLO cycles MIXER / GROOVE / DEMO / AUTOMATION / MIDI / ANALOG. ANALOG knob 1 sets independent melodic-part variance from 0-127; zero is off and drums are excluded. In MIXER: SELECT-ARP to mute. Orange marks selection; bright green underlines flow below populated rows during playback. Small screen text is 6x9. All menu and OCT buttons are lit; selected menus blink at 2 Hz, PLAY pulses at the sequencer tempo and HOME stays lit while playing.

ARP / RECORDING

ARP opens the melodic arpeggiator: MODE / RATE / OCT / GATE; LFO toggles latch. Choose UP, DOWN, UPDOWN, ORDER, RANDOM or CHORD. REC with PLAY records generated notes and sound, mixer and effect knob changes on the 16-step grid. GLO → GROOVE → KNOB4 toggles METRO: clicks only with PLAY and REC, even when all tracks are muted. GLO's AUTOMATION page shows event capacity; EDIT clears the current pattern's automation.

STEP EDIT / DRUMS

EDIT toggles note entry; keys enter a note at the selected step. Drum knobs select SOUND / STEP / HIT / LEVEL. ENV adjusts melodic ADSR. REC records live notes quantized to the current step.

SONG / MIDI

SEQ toggles SONG mode. Press EDIT to unlock the arrangement; four knobs set POS / PATTERN / REPEAT / LENGTH. LFO toggles LOOP. An empty song needs LENGTH before PLAY. GLO five times opens MIDI: the four knobs set track channels; LFO cycles INTERNAL / USB / TRS clock. Browser MIDI input uses USB. Open MIDI ports above to connect an OS input/output; REC with PLAY captures incoming notes. Incoming messages are not echoed.

SAVE AND LIMITS

SAVE twice while stopped writes the actual C A/B project format to emulated flash, persisted in IndexedDB. Reload restores it. Browser storage can be cleared by your browser. MC-1 1.2.0 hardware supports dual-core synthesis/FX processing. This browser runs the same synth/UI semantics in one AudioWorklet; it does not emulate WL82 CPU1 timing or failures. Web MIDI uses OS-exposed ports with your permission. Audio uses the browser’s stereo output. No direct USB audio device emulation, direct BLE connection, calibration or hardware timing guarantees.
